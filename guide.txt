============================================================
 NetSeer — AI-Based Network Attack Forecasting
 ============================================================

 WHAT IS THIS PROJECT?
 ---------------------
 NetSeer is a security guard with a crystal ball. It watches a
 network's normal activity, learns the "rhythm" of how attacks
 unfold, and then predicts what an attacker is going to do next
 before it happens.


 THE IDEA
 --------
 Every network has computers talking to each other and to the
 internet. An attack is not a single event — it is a SERIES OF
 STEPS:

   scan the network → find a weak door → break in
   → sneak around → send data out

 NetSeer's job is to recognize those steps as they start, and to
 forecast the rest of the chain — like a weather forecaster who
 sees a dark cloud and predicts rain.


 HOW IT WORKS (STEP BY STEP)
 ---------------------------

 1. TURN TRAFFIC INTO "CALL RECORDS"     (src/data/)
    Raw network data (PCAP file or flow CSV) is sliced into
    individual connections: "Computer A talked to Server B,
    300 packets, 2.1 MB, lasted 4 seconds."
    Think of it like a phone bill that itemizes every call.

 2. GIVE EACH CALL A SCORECARD           (feature_extractor.py)
    For every connection we compute ~68 numbers: how much data
    flowed, in which direction, packet counts, timing gaps,
    flags... like a health-checkup report for each conversation.

 3. TAKE SNAPSHOTS OF THE NETWORK        (state_builder.py)
    Every 60 seconds, all calls in that minute are mashed into
    one STATE VECTOR — a single "mood of the network right now".
    PCA squeezes it down to 76 numbers. Result: a filmstrip of
    snapshots #1, #2, #3, ...

 4. TEACH THE BRAIN (THE WORLD MODEL)    (src/models/)
    The heart is a TRANSFORMER neural network (the same family
    of tech ChatGPT uses). We show it the last 16 snapshots and
    tell it to guess snapshot #17. Doing this thousands of times,
    it learns the RULES of network behavior — not by memorizing
    attacks, but by understanding how one state flows into the
    next. That is the "world model": a little simulation of the
    network.

 5. PREDICT THE FUTURE LIKE A CHESS PLAYER (rollout_engine.py)
    Feed in the last 16 snapshots → predict #17 → pretend #17
    happened → feed 15 old + #17 → predict #18 → ... for K steps.
    Each step it also outputs:
      * INFILTRATION PROBABILITY  — how likely (0-100%) an
        attacker is inside the network
      * PREDICTED STAGE            — where on the attack line we
        are: benign → recon → break-in → lateral movement
        → command & control → exfiltration

 6. MAKE IT USEFUL                 (alert_generator.py + mitre_mapper.py)
    Probabilities become alerts with severity (LOW → CRITICAL).
    Each alert is matched to the MITRE ATT&CK framework (a giant
    encyclopedia of real attack techniques), so it tells you:
    "This looks like port scanning (T1595) — here is how to fix it."

 7. SHOW YOUR WORK (EXPLAINABILITY)
    Because it is a neural network, we prove WHY it made a call:
      * ATTENTION WEIGHTS — which past snapshots it was "looking
        at" while predicting
      * SHAP — which features (e.g. "lots of tiny packets going
        out") pushed it toward "attack"

 8. PUT IT ON A DASHBOARD          (Streamlit)
    Four pages:
      * DASHBOARD   — live threat meter, forecast timeline, alerts
      * ANALYSIS    — deep dive with SHAP + attention weights
      * BENCHMARKS  — model vs. simpler baseline models
      * ABOUT       — project documentation


 TECHNOLOGIES USED
 -----------------
   Python              the whole system
   PyTorch             builds/trains the transformer neural network
   scikit-learn        PCA compression + Logistic Regression baseline
   SHAP                explains WHY the model predicted an attack
   Streamlit           the dark-themed dashboard
   Plotly              the interactive charts/graphs
   Scapy               reads raw PCAP packet captures
   pandas / NumPy      data tables and math
   YAML (config.yaml)  all settings in one readable file
   unittest / pytest   automated tests


 HONEST CAVEAT
 -------------
 Like weather forecasting, predictions are probabilities, not
 promises. The current demo runs on synthetic data where the model
 scores near-perfectly — those numbers prove the PIPELINE works,
 not that it is foolproof against real-world attacks. Use the
 real CIC-IDS-2018 dataset for production-grade reporting.
